# NASA Space Apps Challenge 2026 Dashboard

English | [한국어](README.ko.md)

Live site: https://nsac2026-dashboard.devstory.co.kr

An unofficial static site showing mission, region and team statistics for NASA Space Apps Challenge 2026. Browse how many teams submitted, how they are spread across regions and countries, and which teams took on each mission, with links to their intro, demo and source code.

> This project is not affiliated with NASA or the Space Apps Challenge organizers. It is built from information published on the [official site](https://www.spaceappschallenge.org); please check the official site for accurate and up-to-date information. Teams that did not submit a final project are excluded from the statistics.
