# NASA Space Apps Challenge 2026 Dashboard

[English](README.md) | 한국어

NASA Space Apps Challenge 2026의 미션·지역·팀 통계를 보여주는 비공식 정적 웹 페이지입니다. 최종 제출 팀이 몇 팀인지, 지역과 국가별로 어떻게 분포하는지, 각 미션에 어떤 팀이 참여했는지를 소개·데모·소스 링크와 함께 볼 수 있습니다.

> 이 프로젝트는 NASA 또는 NASA Space Apps Challenge 주최 측이 운영하는 공식 프로젝트가 아닙니다. [공식 사이트](https://www.spaceappschallenge.org)에 공개된 정보를 바탕으로 만들었으며, 정확한 최신 정보는 공식 사이트에서 확인하세요. 최종 제출되지 않은 팀은 통계에서 제외했습니다.
