무엇을 하는가

여러분은 화성 Gale 크레이터의 기지에서 우주비행사 네 명을 이끕니다. 귀환선은 Sol 120에 착륙합니다. 매 턴 크루의 작업을 고릅니다. 태양광 패널 청소, 예비 패널 설치, 온실 확장, 폭풍 대피소 건설 또는 보강, 물 벽 추가, 산소 생성기 수리, 휴식 중에서 선택합니다. 확정하기 전에, 작업에 걸리는 시간과 전력, 공기와 물, 식량, 건강, 피로, 방사선 선량에 미치는 영향을 예측해 보여 줍니다. 그런 다음 일일 계획(식사, 작업 속도, 온실, 생명 유지)이 자동으로 실행되며 시간이 솔 단위로 흐릅니다. 태양 폭풍, 먼지 폭풍, 고장, 예비 자원 부족 같은 중요한 일이 생길 때마다 시간이 멈춥니다.

절충을 가르치는 방식

- 생명 유지 장치와 온실이 하나의 전력 공급원을 함께 씁니다.

- 온실은 크루가 마시기도 하고 공기로 바꾸기도 하는 같은 물을 마십니다.

- 차폐는 폭풍 때 크루를 보호하지만, 만들려면 여러 솔 동안 바깥에서 작업해야 합니다.

- 빠르게 일하면 일찍 끝나지만 크루가 지치고, 지친 크루는 느리게 일합니다.

- 산소 생성기가 고장 나면 Mission Control(관제 센터)의 지시를 기다리거나 직접 수리를 시작할 수 있습니다. 화면에 표시되는 무선 지연은 대략적인 궤도 추정값입니다. 지시를 기다리는 2솔(Standard) / 3솔(Hard)에는 단순화한 엔지니어링 대응 시간이 포함되며, 직접 시작한 수리는 더 오래 걸립니다.

- 현재 건강과 누적 방사선 선량은 별개입니다. 휴식과 식량으로는 선량을 결코 되돌릴 수 없습니다.

대가 없는 안전한 선택은 없습니다. 자동화 테스트 임무에서 아무것도 하지 않는 크루는 한 번도 임무를 완수하지 못합니다.

다시 플레이하게 만드는 요소

임무마다 서로 다른 실제 폭풍이 뽑힙니다. 실패는 "긴급 귀환"이며, 같은 임무를 새로운 계획으로 다시 플레이할 수 있습니다. Standard 임무를 마치면 건설이 더 느리고, 예비 자원이 더 적으며, 폭풍이 네 번이고, 5솔짜리 폭풍 감시 기간에 맞춰 계획해야 하는 Hard 임무가 열립니다. 결과 화면은 크루의 추정 선량을 추가한 대피소나 물 벽 차폐가 없는 같은 임무와 비교하고(두 경우 모두 기본 거주 모듈 방호는 유지됩니다), 모든 솔을 차트로 그리며, 플레이어가 마주한 절충을 나열합니다.

제작 방법

React, TypeScript, Vite로 만들었고 GitHub Pages에 정적 사이트로 배포했습니다. 시뮬레이션은 인터페이스와 분리된 순수 TypeScript이며, 단위 테스트와 균형을 점검하는 자동 플레이어가 있습니다. 게임 아트는 AI 코딩 지원을 받아 작성한 SVG 코드로 렌더링합니다. 게임은 데스크톱, 태블릿, 휴대전화에서 작동하며 영어와 한국어를 지원합니다. 실시간 우주 기상은 플레이어의 브라우저에서 요청하며, 보관된 기록을 명확히 표시한 대체 데이터로 사용합니다.
