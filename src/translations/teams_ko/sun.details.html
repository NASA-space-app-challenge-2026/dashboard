SUN: Lunar Outpost — 프로젝트 상세

1. 프로젝트 개요

SUN: Lunar Outpost는 NASA Space Apps Challenge 2026을 위해 개발한 인터랙티브 달 생존·탐험 게임으로, "주니어 우주비행사 임무 트레이너 만들기" 챌린지에 도전합니다.

저희의 목표는 인터랙티브한 게임 플레이를 통해 초등학생과 중학생이 우주 과학을 이해하기 쉽고 흥미롭게 느끼도록 하는 것입니다.

학생들은 달에서 생활하는 어려움을 글로 읽는 데 그치지 않고, 자원 관리, 탐험, 문제 해결, 과학적 의사 결정을 통해 직접 경험합니다.

2. 게임 진행 방식

플레이어는 달 남극 인근에 위치한 가상의 3인 달 연구 기지 SUN-01을 운영합니다.

세 개의 챕터로 나뉜 12번의 가상 교대 근무 동안, 플레이어는 다섯 가지 필수 시스템을 관리해야 합니다.

  • 전력: 태양광 발전을 하고 배터리 예비량을 관리합니다.
  • 산소: 산소 재활용 시스템을 가동해 대원을 지원합니다.
  • 식량: 온실 생산과 식량 보급품을 관리합니다.
  • 대원 안전: 장비 고장과 방사선 비상 상황에 대응합니다.
  • 과학 연구: 연구를 수행하고 과학 목표를 달성합니다.

모든 결정에는 상충 관계가 따릅니다. 시설을 추가로 가동하면 생존 환경은 나아지지만 전력을 더 소비합니다. 플레이어는 달 기지가 계속 운영되도록 신중하게 계획해야 합니다.

게임에는 세 가지 인터랙티브 로버 임무도 포함됩니다.

  1. 태양광 장비 수리: 달 지형을 이동하고 전기 회로 퍼즐을 풉니다.
  2. 산소 시스템 수리: 장비를 운반하고, 누출을 조사하고, 압력을 안정시킵니다.
  3. 과학 탐사: 달 표면을 탐험하고 과학 시료를 채취합니다.

플레이어는 햇빛 구역과 그림자 구역을 이동하면서 로버의 배터리 소모를 관리해야 합니다.

3. NASA 데이터 활용

이 프로젝트는 NASA Lunar Reconnaissance Orbiter(LRO), 그중에서도 Lunar Orbiter Laser Altimeter(LOLA)의 실제 달 일조 데이터를 반영합니다.

사용한 NASA 데이터 산출물은 다음과 같습니다.

AVGVISIB_85S_060M_201608

이 데이터셋은 달 남극의 장기 평균 태양 가시성 정보를 제공합니다.

이 단일 데이터 산출물에서 세 위치의 값을 추출했습니다.

  • 선택한 SUN-01 부지: 평균 태양 가시율 약 88.44%.
  • 주변 300 m × 300 m 영역: 약 55.36%.
  • 비교용 Shackleton 크레이터 바닥: 약 0%.

88.44%라는 값은 장기 관측 모델에서 태양의 일부라도 보이는 시간의 비율을 나타냅니다. 태양광 패널의 효율을 나타내는 값이 아닙니다.

저희는 이 실제 과학 측정값을 게임의 태양 에너지 시뮬레이션 입력값으로 사용합니다.

이를 통해 학생들은 달 연구 기지를 설계할 때 위치 선정과 햇빛의 가용성이 왜 중요한지 이해할 수 있습니다.

자원 소비, 비상 상황, 로버 배터리 동작, 교대 근무별 조건은 NASA의 직접 측정값이 아니라 단순화한 가상의 훈련용 값입니다.

NASA 데이터셋:
https://pgda.gsfc.nasa.gov/products/69

4. 기술과 구현

SUN: Lunar Outpost는 다음을 사용해 브라우저 기반 게임으로 개발했습니다.

  • React
  • TypeScript
  • Vite
  • HTML Canvas
  • 절차적으로 렌더링한 픽셀 아트와 2.5D 그래픽
  • 효과음과 배경 음악을 위한 Web Audio API
  • 진행 상황 저장을 위한 브라우저 로컬 저장소

게임은 영어와 한국어, 세 가지 난이도(Easy, Normal, Hard), 인터랙티브 튜토리얼, 키보드·마우스·터치스크린 조작을 지원합니다.

작은 픽셀 아트 우주비행사가 초보자에게 주요 게임 방식을 안내합니다.

게임은 설치나 계정 없이 최신 웹 브라우저에서 바로 실행됩니다.

5. 창의성과 교육적 효과

저희의 접근 방식은 전략 기반의 달 생존 시뮬레이터에 인터랙티브한 로버 탐험과 과학 교육을 결합한 것입니다.

학생들은 결정을 내리고 그 결과를 관찰하며 배웁니다.

게임은 다음과 같은 중요한 개념을 가르칩니다.

  • 재생 에너지와 태양 일조
  • 우주에서의 제한된 자원
  • 배터리와 전력 관리
  • 생명 유지 시스템
  • 과학 탐사
  • 위험 평가와 문제 해결

기존의 과학 퀴즈와 달리, 이 게임은 학생들이 과학 지식을 적용해 임무를 완수하도록 유도합니다.

픽셀 아트 시각 스타일, 안내형 튜토리얼, 조절 가능한 난이도는 어린 학습자가 복잡한 우주 과학에 더 쉽게 다가가도록 설계한 것입니다.

6. 개발과 테스트

이 프로젝트는 Claude Code와 OpenAI Codex를 비롯한 AI 지원 프로그래밍 도구를 활용해, 팀의 프로젝트 기획, 지휘, 테스트, 검토 아래 개발했습니다.

개발 과정에는 게임 플레이 설계, 구현, 시뮬레이션 밸런스 조정, 자동화 테스트, 시각적 개선, 접근성 조정, 브라우저 호환성 점검이 포함되었습니다.

게임의 시뮬레이션 시스템, 자원 계산, 로버 작동 방식, 튜토리얼 동작, 오디오 기능에 대해 자동화 테스트를 거쳤습니다.

브라우저와 반응형 레이아웃 테스트도 수행했습니다. 다만 모든 실제 모바일 기기에서의 호환성이 완전히 검증된 것은 아닙니다.

7. 한계와 향후 개선

SUN: Lunar Outpost는 교육용 시뮬레이션이며, 과학적으로 완전한 달 공학 모델이 아닙니다.

게임은 NASA의 실제 일조 측정값을 사용하지만, 방사선 노출, 자원 소비, 로버 에너지 사용, 장비 운용 같은 현실의 시스템은 어린 학생들이 이해할 수 있도록 단순화했습니다.

향후 개선 사항으로는 NASA 데이터셋 추가, 더 상세한 달 지리, 새로운 과학 실험, 임무 확장, 교실 학습 기능 등이 있습니다.

저희의 장기 비전은 SUN: Lunar Outpost를 어린 학생들이 인터랙티브한 경험을 통해 우주 과학, 공학, 문제 해결을 탐구하도록 북돋우는, 누구나 접근하기 쉬운 플랫폼으로 발전시키는 것입니다.
