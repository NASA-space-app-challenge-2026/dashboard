SanBool24 — 프로젝트 개요

① 문제

NASA FIRMS 화재 기록은 MODIS(2000년부터)와 VIIRS(2012년부터)라는 두 위성 센서에 걸쳐 있습니다.

VIIRS는 픽셀 크기가 더 작아 작은 불을 훨씬 많이 탐지합니다. 대한민국에서 VIIRS는 MODIS보다 약 2.4배 많은 화재 탐지 건수를 기록합니다.

두 데이터셋을 단순히 합치면 2012년 이후 화재 활동이 급증했다는 잘못된 인상을 줍니다. 대한민국의 경우 보정하지 않은 연간 추세는 +8.2%인 반면, 보정 후에는 +0.6%에 불과합니다.

이러한 왜곡은 탄소 크레딧 위험 평가, 보험금 청구, 산불 관리 예산을 그릇된 방향으로 이끌 수 있습니다.

② 대상 사용자

  • 탄소 크레딧 사업 관리자: Verra는 산림 탄소 사업에 과거 산불의 빈도와 심각도에 대한 증거 제출을 요구합니다. 2021년 미국 Bootleg Fire 이후에는 버퍼 풀에서 크레딧 114만 개가 소각되었습니다.
  • 보험 손해사정 담당자: 특정 장소와 시각에 화재가 발생했다는 신뢰할 수 있는 증거가 필요합니다.
  • 정부 산불 담당 공무원: 산불 발생 시기, 이전 기간 대비 올해의 상황, 예산 요청을 뒷받침할 근거에 관한 정보가 필요합니다.

③ 해결책

화재 탐지 필터링

  • 확정된 과거 데이터는 FIRMS의 type 필드를 사용해 식생 화재로 추정되는 건(type = 0)만 남깁니다.
  • 2026년 실시간 데이터에는 type 필드가 없습니다. 확정 데이터에서 확인한 상시 열원의 위치를 약 1 km 격자 셀로 묶어 이 필드를 채웁니다.

센서 조화 모델

  • 화재 탐지 결과를 0.5° 격자의 월별 값으로 집계합니다.
  • 단조 제약과 Tweedie 손실을 적용한 LightGBM으로 VIIRS 관측값을 MODIS 환산 탐지 건수로 변환합니다.
  • 학습 기간은 2012년 2월부터 2024년 12월까지입니다. 2025년은 Terra의 궤도 변화로 MODIS가 과소 집계했기 때문에 제외했습니다.
  • 영향력이 가장 큰 특성은 화재 복사 강도(FRP, 35%), VIIRS 탐지 건수(27%), 위치(15%)입니다.
  • VIIRS를 MODIS에 맞춰 보정하는 이유: MODIS는 2000년까지 거슬러 올라가는 유일한 연속 기록입니다. 이를 기준으로 삼으면 과거 관측값을 바꾸지 않고 기록을 연장할 수 있습니다.

NOAA-20을 이용한 기록 연장

  • 2026년에는 S-NPP 준실시간 데이터가 중단되어 NOAA-20을 대신 사용합니다.
  • 재학습하지 않아도 NOAA-20은 S-NPP보다 오차가 낮았습니다(118.9 대 149.6).

대한민국 공간 다운스케일링

  • 각 0.5° 셀의 보정값을 해당 셀 안의 개별 탐지 지점에 배분합니다.
  • 이를 통해 행정구역(시, 군)과 지도에 직접 그린 영역에 대한 계산이 가능합니다.
  • 실제 MODIS 관측값과의 상관계수는 0.1°에서 0.78, 0.2°에서 0.87입니다. 단순 면적 비례 배분은 0.32와 0.45에 그칩니다.

화재 강도 보정

  • 같은 방식으로 FRP(MW)를 보정했습니다. 이 방식은 단순 비율법에 비해 오차를 39% 줄였습니다.

해시 코드를 이용한 계정 없는 보고서 관리

  • 발급된 보고서마다 고유한 12자리 해시 코드가 부여됩니다.
  • “Find by hash”(해시로 찾기)에 코드를 입력하면 저장된 원본을 불러오므로, 사용자는 보고서를 검증하고 다시 내려받을 수 있습니다.
  • 설계 근거: 누구나 바로 서비스를 이용할 수 있도록 로그인 요건을 없앴습니다. 계정이 없으면 개인 문서 보관함도 없으므로, 하나의 코드가 조회와 검증을 모두 담당합니다.
  • 인증 기관, 보험사, 예산 부서 같은 보고서 수신자도 계정 없이 코드만으로 원본을 확인할 수 있습니다.

최종 조화 데이터셋

  • 2000년 11월부터 2026년 11월까지의 연속 화재 기록 하나: 격자-월 레코드 5,384,508건.
    • 2000–2002년: Terra 보정 관측값
    • 2002–2024년: MODIS 직접 관측값
    • 2025년 이후: MODIS 기준선으로 변환한 VIIRS 값(불확실성 구간 포함)

④ 검증

모델 성능

  • 2020년부터 2024년까지 각 연도를 하나씩 따로 떼어 두고, 그 이전 연도로 학습한 뒤 떼어 둔 연도로 시험했습니다.
  • 저희 모델의 오차는 가장 우수한 규칙 기반 기준선보다 33% 낮았습니다(149.6 대 221.1).
  • 다섯 개 시험 연도 모두에서 기준선을 앞섰으며, 전체 편향은 −0.3%였습니다.

불확실성 보정

  • 명목 80% 예측 구간의 실측 포함률은 81.4%였습니다.

화재 활동 지수

  • 화재 활동을 과거 평년 수준과 비교하는 저희의 5단계 지수는 등급 일치율 67%를 기록했습니다. 센서별 지수를 단순히 합친 경우는 52%였습니다.

대한민국의 장기 추세

  • 보정 전: 연 +8.2%
  • 보정 후: 연 +0.6%
  • 겉보기 증가의 상당 부분은 화재 활동의 변화가 아니라 센서 성능 차이에서 비롯됩니다.

⑤ 구현된 서비스 기능

  • 로그인이나 회원 가입 없이 바로 이용
  • 행정구역(시·도, 시·군·구) 선택 또는 지도에 원하는 영역 직접 그리기
  • 12개 데이터 항목: 화재 관측 요약, 화재 관측 위치, 월별 관측 추세, 관측 신뢰도, 연간 화재 추세, 대형 화재 빈도, 고위험 시기, 가장 가까운 화재, 화재 강도 등급, 주야간 비교, 이전 기간 비교, 화재 핫스팟
  • 한국어 또는 영어 보고서 미리보기 및 PDF 다운로드
  • 발급 보고서마다 고유한 12자리 해시 코드
  • 검증 및 재다운로드를 위한 “Find by hash”(해시로 찾기)
  • 홈페이지의 25년 산불 타임랩스
  • Sentinel-2 위성 지도

⑥ 기대 효과

  • 탄소 크레딧 사업: 2000년까지 거슬러 올라가는 일관된 기록을 바탕으로 한 증거 기반 산불 위험 평가.
  • 보험금 청구: 특정 장소와 시각의 화재 관측 증거를 담은 하나의 보고서.
  • 지방자치단체: 관측된 산불 발생 시기와 장기 패턴을 중심으로 산불 예산 수립.
  • 검증 가능한 보고서: 수신자는 12자리 코드로 저장된 원본을 불러와 받은 사본과 대조할 수 있습니다.
  • 지금 이것이 중요한 이유: 문제는 이미 존재합니다. 2025년부터 Terra의 궤도 변화로 MODIS가 약 9% 과소 집계하고 있어, 저희 시스템은 2025년 이후에 대해 이미 VIIRS를 보정한 MODIS 환산값을 사용합니다.

⑦ 한계와 다음 단계

현재의 한계

  • 보정값은 탐지 지점에 배분되지만, MODIS의 위치 정확도 불확실성이 약 1–5 km이므로 약 5 km보다 작은 영역은 의미가 없습니다. 이 시스템은 필지 단위의 결정을 지원할 수 없습니다.
  • 이 데이터는 연소 면적이 아니라 화재 탐지 건수를 측정합니다.
  • 계정이 없으므로 코드를 분실하면 이전에 발급한 보고서를 불러올 수 없습니다.

향후 개발

  • 전 지구 확장: 조화 모델은 이미 전 지구 0.5° 데이터로 학습되어 있습니다.
  • 시범 사업: 탄소 크레딧 사업 및 지방자치단체와 협력해 플랫폼을 실제 환경에서 시험합니다.
  • 연소 면적 통합: 연소 면적 데이터를 추가해 산불의 영향을 더 온전히 파악합니다.

⑧ 기술 스택

  • 데이터 처리 및 머신러닝: Python, DuckDB, pandas, LightGBM, pytest
  • 백엔드: Java 21, Spring Boot 4.1, JPA, MyBatis, PostgreSQL 17 + PostGIS 3.5, Flyway, Docker Compose, AWS S3(발급 보고서 저장)
  • 프런트엔드: React 19, TypeScript, Vite, TanStack Query, i18next(한국어/영어), jsPDF, html2canvas
  • 배포: Cloudflare Workers(프런트엔드), GitHub Actions를 사용하는 AWS EC2(백엔드)
