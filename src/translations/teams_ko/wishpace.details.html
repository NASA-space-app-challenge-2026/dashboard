프로젝트 개요

저희 프로젝트는 NASA의 Physical Sciences Informatics(PSI) 저장소에 있는 연소과학 데이터를 탐색하는 AI 지원 환경입니다. 대화형 데이터 발견, 인터랙티브 시각 분석, 데이터 기반 불꽃 시뮬레이션을 하나의 작업 흐름으로 연결해, 연구자가 실험 관측에서 가설 생성과 예비 검증으로 나아가도록 돕습니다.

작동 방식과 주요 기능

1. Playground: 대화형 데이터 발견

사용자는 AI 데이터 탐색 에이전트인 ddonguri와 대화하며 연구 목표에 관련된 데이터를 찾고, 선택하고, 이해합니다. 계층적 온톨로지가 데이터를 구조화하고 탐색을 안내합니다. 대화가 이어질수록 온톨로지는 각 사용자의 필요에 점점 더 맞춰집니다.

2. Data Explorer: 인터랙티브 시각 분석

사용자는 인터랙티브 시각화를 통해 PSI 원본 기록, 실험 조건, 결과를 탐색합니다. 이를 통해 불꽃의 거동을 해석하고, 관측 결과를 비교하며, 실험 조건이 연소 거동과 어떤 관계가 있는지 이해할 수 있습니다.

3. Laboratory: 데이터 기반 불꽃 시뮬레이션

사용자는 Donggeuri와 함께 가상 환경 조건을 조정하고 불꽃 거동의 차이를 탐색합니다. NASA 실험 데이터를 바탕으로 한 물리 기반 불꽃 시뮬레이션 엔진은 실험 데이터가 여전히 제한적인 부분중력 조건의 탐색을 포함해 가설 생성과 예비 검증을 지원합니다. 시뮬레이션 결과는 기존 실험 관측과 연관 지어 제시합니다.

4. 이중 언어 인터페이스

인터페이스는 영어와 한국어를 지원해, 두 언어 모두로 데이터를 탐색하고 ddonguri와 대화할 수 있습니다.

기술 스택

  • 프로그래밍 언어: Python, JavaScript
  • 백엔드: FastAPI
  • 에이전트–도구 연동: Model Context Protocol (MCP)
  • 컨테이너화: Docker
  • 프런트엔드: React, Vite
  • 인터랙티브 그래픽: WebGL

프로젝트의 창의성

이 프로젝트는 친근한 AI 가이드, 개인화된 온톨로지, 인터랙티브 시각화, 불꽃 시뮬레이션을 하나로 연결된 연구 환경에 담았습니다. 창의적인 기여는 관련 증거를 찾고, 이해하고, 이를 활용해 새로운 가설을 탐색하는 과정이 끊김 없이 이어진다는 점입니다. Ddonguri는 데이터 발견과 시뮬레이션 전반에 걸쳐 익숙한 대화형 인터페이스를 제공합니다.

이점과 기대 효과

프로젝트의 목표는 다음과 같습니다.

  • 안내형 대화와 직관적인 시각적 상호작용을 통해 대규모 실험 데이터셋을 더 쉽게 이해하고 분석할 수 있게 합니다.
  • 온톨로지를 사용해 각 사용자의 목표를 중심으로 데이터를 선택하고 정리함으로써 연구 관련성을 높입니다.
  • 실험 범위가 제한적인 조건을 포함해, NASA 실험 데이터를 바탕으로 한 불꽃 시뮬레이션으로 우주 환경의 연소 탐구를 지원합니다.

기대 효과는 접근하기 쉬운 작업 흐름 안에서 실험 증거, 데이터 해석, 시뮬레이션을 연결해 우주 화재 안전 연구를 가속하는 것입니다.

설계 고려 사항

  • 데이터 양과 연구 관련성: 연구자가 자신의 질문과 가장 관련 있는 실험 기록에 집중하도록 돕습니다.
  • 실험 맥락: 의미 있는 해석과 비교가 가능하도록 결과와 함께 실험 조건을 제시합니다.
  • 제한적인 부분중력 데이터: 실험 관측이 부족한 영역에서는 시뮬레이션으로 가설을 생성하고 예비 검증합니다.
  • 사용성과 개인화: 친근한 에이전트, 인터랙티브 시각화, 지속적인 상호작용에 따라 적응하는 온톨로지를 결합합니다.
  • 언어 접근성: 영어와 한국어 인터페이스를 모두 지원합니다.
