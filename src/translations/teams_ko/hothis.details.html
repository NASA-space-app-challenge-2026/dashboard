Space Garden Simulator — Hothis Groot Gardener

프로젝트 개요

Space Garden Simulator는 우주에서 채소를 재배할 때의 어려움을 사용자가 이해할 수 있도록 설계한 인터랙티브 웹 기반 시뮬레이션입니다. NASA Space Apps Challenge 2026을 위해 개발한 이 프로젝트는, 국제우주정거장(ISS)의 Veggie 식물 생장 시스템을 모사한 환경에서 Outredgeous 적로메인 상추를 재배하는 데 초점을 맞춥니다.

장기 우주 임무를 수행하는 우주비행사는 저장 식품에 크게 의존하므로, 지속 가능한 식량 생산은 중요한 연구 분야입니다. 우주에서 신선한 채소를 재배하면 우주비행사의 식단을 보충하고 안녕을 지원하는 데 도움이 될 수 있습니다. 하지만 미세중력에서 작물을 건강하게 유지하려면 수분 관리, 공기 흐름 제어, 미생물 오염 같은 어려움을 해결해야 합니다.

저희 프로젝트에서 사용자는 실제 NASA 식물 생장 실험을 바탕으로 재배 결정을 내리며 이러한 어려움을 경험할 수 있습니다.

프로젝트 작동 방식

시뮬레이션은 33일의 상추 재배 기간을 7일의 인터랙티브 게임 일자로 표현합니다.

사용자는 식물 건강, 뿌리 수분, 챔버 습도, 팬 작동, 조명 조건을 관찰합니다. 급수, 공기 흐름, 조명을 조절하면서 시뮬레이션 환경이 시간에 따라 어떻게 변하는지 지켜볼 수 있습니다.

재배 중에 사용자는 NASA 실험에서 기록된 문제를 바탕으로 한 위기 시나리오를 마주합니다. 여기에는 물 공급 부족, 그리고 과도한 습기와 공기 흐름 부족이 겹쳐 곰팡이 발생에 영향을 줄 수 있는 상황이 포함됩니다.

위기가 발생하면 시스템은 식물의 증상과 선택 가능한 여러 조치를 제시합니다. 사용자가 조치를 선택하면, 시뮬레이션은 과학 연구에 근거해 미리 정의한 규칙으로 그 결정을 평가합니다. 사용자의 선택은 식물의 상태와 이후 게임 진행에 영향을 줍니다.

각 단계에서 시스템은 사용자 결정의 결과를 설명하는 보고서를, 그 결과를 뒷받침하는 과학적 근거 및 참고 자료와 함께 제공합니다. 이를 통해 사용자는 자신의 행동이 식물 생장에 어떤 영향을 주는지 이해하고, 각 결과의 과학적 논거를 살펴볼 수 있습니다.

임무가 끝나면 사용자는 상추를 수확하고 시료 처리 절차를 마친 뒤, 시뮬레이션 결과를 ISS에서 재배한 상추의 실제 측정값과 비교한 최종 보고서를 확인합니다.

AI와 검색 증강 생성

이 프로젝트는 연구에 근거한 인터랙티브 시나리오를 제공하기 위해 대규모 언어 모델(LLM)과 선택 사항인 검색 증강 생성(RAG) 시스템을 통합합니다.

저희 RAG 데이터베이스에는 우주 식물 재배 관련 과학 연구 자료에서 추출한 텍스트 청크 81개가 들어 있습니다. Python 기반 FastAPI 검색 서버가 BM25 키워드 검색으로 관련 구절 4개를 찾아 LLM에 추가 맥락으로 제공합니다.

텍스트 생성에는 Ollama를 통해 로컬에서 실행하는 Google의 Gemma 4 E4B 모델을 사용합니다. 이 모델은 위기 설명, 상추 캐릭터의 대사, 증상 단서, 조치 설명, 사용자의 선택에 대한 반응을 생성합니다. 한국어 번역도 지원합니다.

중요한 설계 결정 중 하나는 AI가 생성하는 서술과 게임 로직을 분리한 것입니다. LLM은 어떤 조치가 올바른지 판정하거나, 식물 건강 변화를 계산하거나, 과학적 근거를 생성하지 않습니다. 이러한 결정은 시뮬레이션 엔진과 검증된 근거 데이터베이스가 담당합니다.

AI가 생성하는 부정확하거나 오해를 부르는 콘텐츠를 줄이기 위해 구조화된 JSON 출력, 검증 규칙, 자동 수정 시도, 대체 시나리오를 구현했습니다. 생성한 텍스트가 검증에 실패하면, 시스템은 게임 진행을 중단하지 않고 미리 작성한 콘텐츠를 사용합니다.

개발 과정에서 생성 시나리오를 반복해서 테스트하며 검증 절차를 다듬었습니다. 기록으로 남긴 최종 테스트에서는 위기 생성 6건이 모두 첫 시도에 검증을 통과했으며, 영어 기준 평균 생성 시간은 12.0초였습니다.

기술과 도구

이 프로젝트는 다음 기술을 사용합니다.

  • 프런트엔드 및 시뮬레이션: Next.js, React, TypeScript, HTML, CSS
  • 백엔드 및 AI 통합: Python, FastAPI, 서버 사이드 TypeScript
  • 언어 모델: Ollama를 통해 로컬에서 운용하는 Google Gemma 4 E4B
  • 정보 검색: BM25, ChromaDB, 연구 기반 RAG 데이터
  • 데이터 관리: JSON 기반의 과학적 근거, 게임 규칙, 시뮬레이션 기록
  • 개발 도구: Node.js, npm, Git, GitHub, Claude Code
  • 하드웨어: 언어 모델을 실행할 수 있는 로컬 개발용 노트북(GPU 가속 권장)

시뮬레이션은 LLM 서버가 작동하지 않아도 실행할 수 있어, 사용자는 미리 작성한 시나리오로 전체 과정을 체험할 수 있습니다.

창의성과 혁신

Space Garden Simulator의 두드러진 특징 중 하나는 과학적 근거, 인터랙티브 의사결정, 대화하는 식물 캐릭터를 결합한 것입니다.

이 프로젝트는 연구 결과를 정적인 정보로 제시하는 대신, 기록된 재배 문제를 사용자가 직접 대응해야 하는 상황으로 바꿉니다. 상추 캐릭터가 증상과 반응을 전달해, 전문적인 식물 관리 개념에 더 쉽게 몰입할 수 있습니다.

또 하나의 중요한 특징은 생성형 AI와 근거 기반 의사결정의 분리입니다. 사용자 행동의 결과는 과학 참고 자료와 미리 정의한 시뮬레이션 규칙이 결정하고, AI는 자연어 생성을 통해 경험을 더 상호작용적으로 만듭니다.

팀은 NASA 연구에 기록된 값과 게임 진행을 위해 설계한 수치도 구분했습니다. 이를 통해 시뮬레이션상의 식물 건강 변화가 실제 과학 측정값처럼 제시되지 않도록 합니다.

기대 효과

Space Garden Simulator는 승무원이 장기 임무를 위한 작물 관리 결정을 연습하도록 돕습니다. 일반 대중이 우주에서 신선한 식량을 생산하는 어려움을 이해하는 데에도 도움이 됩니다.

이 프로젝트가 우주비행사의 건강을 직접 측정하지는 않지만, 건강을 지원하는 데 중요한 조건인 우주에서의 안정적인 신선 채소 공급원 유지를 다룹니다.

물 부족, 과도한 습기, 공기 흐름 문제가 작물 재배에 미치는 영향을 경험하면서, 사용자는 우주 농업에서 환경 모니터링과 적절한 개입이 왜 중요한지 더 잘 이해할 수 있습니다.

또한 이 프로젝트는 과학 연구, 규칙 기반 시뮬레이션, 생성형 AI를 결합해 누구나 접근하기 쉬운 교육 경험을 만들 수 있음을 보여 줍니다.

저희의 목표는 우주 농업 연구를 더 이해하기 쉽게 만들고, 지속 가능한 식량 생산과 미래의 유인 우주 탐사를 지원하는 데 필요한 기술에 대한 관심을 높이는 것입니다.
