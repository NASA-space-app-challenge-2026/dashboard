Project Dawn은 1–4명을 위한 협동 우주 임무 게임입니다. 친구가 있다면 한 명이 HOST A CREW(승무원 팀 만들기)를 선택해 방 코드를 공유하고, 나머지는 JOIN A CREW(승무원 팀 참가)를 선택합니다. 게임 속에서는 오존층이 무너지고 있으며, 너무 많은 자외선(UV)이 지구에 해를 끼치고 있습니다. 각 플레이어는 지구를 구하기 위해 실제 우주 임무에서 착안한 서로 다른 역할을 맡습니다. 역할은 Engineer(엔지니어), Scientist(과학자), Navigator(항법사) 또는 Quartermaster(보급 담당)입니다. 이들은 함께 세 가지 임무를 설계하고 성공시켜야 합니다.

1막 · 지구: 상승하면서 자외선을 측정하는 과학 관측 로켓을 제작해 발사합니다.

2막 · 달: 착륙해 전초 기지를 세우고, 달의 그늘진 크레이터에서 물 얼음을 찾습니다.

3막 · 달에서 L1로: 자외선 차폐막을 만들고 태양과 지구 사이의 L1 지점에 유지합니다.

게임 방식

역할마다 고유한 미니게임이 있으며, 각 미니게임은 실제 NASA의 방법이나 데이터셋에서 착안했습니다.

예시:

1. 40년간의 남극 오존 지도 순위 매기기(NASA Ozone Watch).

2. NASA GMAT으로 계산한 궤적에서 달 도착 연소 타이밍 맞추기.

3. 저온(LRO Diviner)과 낮은 중성자 계수(LRO LEND)가 일치하는 곳에서 얼음 찾기.

4. LCROSS 스펙트럼을 판독해 물 찾아내기.

5. NASA 장비 자료표에서 가져온 실제 질량, 전력, 데이터 한도 안에서 장비 꾸리기.

주요 목적

- 오존층 보호가 얼마나 중요한지 사람들이 깨닫도록 돕는 것.

- 우주를 배우는 학생이 관련 가상 실험을 안전하게 해 볼 수 있는 가교가 되는 것.

- 플레이어가 우주에서의 과학과 물리 원리를 더 잘 이해하도록 돕는 것.

- NASA가 제공한 데이터를 활용해 NASA를 더 잘 이해하도록 돕는 것

목표 달성을 위해 고려한 요소

- 정확성: 모든 수치는 인용한 출처에서 가져왔으며, 사용 전에 데이터를 확인했습니다.

- 접근성: 설치 없이 브라우저에서 실행되며, 혼자서도 온라인으로도 할 수 있습니다.

- 연령에 적합한 언어와, 매 시도 후의 명확한 피드백.

- 공정한 협동 설계로 할 일이 없는 역할이 생기지 않도록 했습니다.

- 초지능(SI)의 공정한 사용

도구와 기술

개발에 앞서 많은 도구를 검토했고, 최종적으로 다음을 주요 개발 도구로 선택했습니다.

1. 게임 엔진:

게임 안의 모든 것은 Godot 4.7에서 GDScript로 작성한 뒤, 브라우저용 WebAssembly로 내보냈습니다. 오픈소스 게임을 만들어 본 익숙한 경험이 있어 Godot를 선택했습니다. 또한 Godot 플랫폼은 다른 도구와 쉽게 통합할 수 있습니다.

2. 온라인 플레이:

원활한 멀티플레이를 위해 HTTPS를 적용한 Caddy 웹 서버 뒤에 Google Cloud 가상 머신을 사용합니다. 처음에는 저희에게 가장 어려운 과제였지만, 멀티플레이가 이 게임의 주요 목표였기에 클라우드 구현이 가장 큰 도움이 되었습니다. 플레이어가 쉽게 함께할 수 있도록 방 코드를 지원하는 Node.js 릴레이를 사용합니다.

3. 데이터 수집:

팀원 한 명이 모든 NASA 데이터를 처리하고 수집하는 Python 스크립트를 작성했습니다. 집중적인 조사 끝에 CSV 파일을 만들었으며, 이 데이터가 게임의 모든 미니게임 설계에 생명을 불어넣는 근간입니다.

4. 팀워크:

코드가 main 브랜치에 병합될 때마다 자동 웹 빌드와 버전 관리가 이루어지는 GitHub를 사용합니다. Whatsapp은 주된 소통 플랫폼입니다.

초지능(SI) 활용

1. 정보 수집을 위한 조사

모든 데이터는 NASA에서 수집했습니다. 더 많은 데이터를 얻기 위해 저희가 작성한 Python 스크립트를 AI로 다듬었습니다. 외부 자료를 찾는 데에도 AI를 사용했으며, 일부 AI는 웹사이트나 출처의 세부 내용을 가져오지 못하기 때문에 이미지 같은 특정 부분은 직접 찾아보았습니다.

2. 데이터 분석 및 해석

데이터를 조작하는 데에는 AI를 전혀 사용하지 않았습니다. AI는 데이터를 더 잘 정리하는 데에만 사용했습니다

3. 문제 해결을 위한 코드 디버깅

코드는 직접 실행하고 버그도 직접 추적합니다. 큰 버그를 발견하면 AI의 조언을 받아 해결합니다. 게임 전체를 실행해 결함을 찾으며, 플레이어 입장에서 개선할 점과 불편한 점을 살핍니다. 대부분을 AI 도움으로 작성한 파일에는 맨 위에 한 줄 주석(예: ## Written with help from an AI assistant (Claude))이 있으며, 팀이 꼼꼼히 검토했습니다.

4. 시각 디자인 및 이미지 제작

사용한 그림 대부분은 저희 데이터 분석 담당자가 찾은 것이므로 출처가 표기되어 있습니다. 스프라이트와 맵 대부분은 사람의 창의성에 AI를 더해 개선한 것이어서 저작권이 저희에게 있습니다. 대부분은 저희가 직접 그리고 설명했으며, AI는 이를 디지털화하는 데 사용했습니다

5. 발표 영상 또는 오디오

메인 배경음과 환호성, 봇 효과음만 AI가 만든 오디오입니다. 그 밖의 오디오는 저작권 문제가 없는 오디오를 조사해 얻은 것입니다. 참고로, 영상도 저희 게임 플레이를 직접 녹화한 것이어서 저작권이 저희에게 있으며, 영상 제작 과정에는 AI를 사용하지 않았습니다.
