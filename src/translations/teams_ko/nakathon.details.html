하는 일과 작동 방식

Crew Health는 장기 화성 임무 대원을 위한 건강 모니터링 소프트웨어입니다. 화성에서는 지구로 보내는 메시지가 수십 분 걸리고, 태양 합(solar conjunction) 기간에는 약 2주 동안 교신이 거의 끊깁니다. 앱은 지구와의 연결 상태(연결, 지연, 두절)에 따라 스스로 행동하는 범위를 바꿉니다.

지연: 수면과 심박변이도(HRV)가 대원 본인의 기준선 아래로 떨어지면 거주 모듈이 선실 조명을 자동으로 조정합니다. 일정 변경은 대원이 승인한 뒤에만 적용되며, 다음 날 회복이 확인되면 두 조치 모두 저절로 해제됩니다.

두절: 흉통 같은 긴급 증상은 AI를 기다리지 않고 규칙에 따라 즉시 경보를 발생시킵니다. 지정된 대원 2명이 각각 동의해야 보고서가 저장됩니다. 교신이 재개되면 이 보고서가 가장 먼저 지구로 전송됩니다.

이점

지친 대원에게 대시보드와 할 일을 더 안기는 대신, 거주 모듈이 먼저 바뀝니다. 되돌리기 어려운 결정은 사람에게 남기며, 모든 조정과 설명에는 근거 문단 링크가 붙습니다.

기대 효과

지구의 의료팀과 연락이 닿지 않을 때 대원이 홀로 결정하도록 내버려 두지 않는 것이 저희의 바람입니다. 같은 접근 방식은 남극 기지나 외딴 지역처럼 연결이 불안정한 다른 곳에도 적합합니다.

사용 도구

프런트엔드: React 19, Vite, React Router, Chart.js, Three.js(3D 인체 보기)

백엔드: Python, FastAPI, SQLite

AI: Gemma 4 12B(4비트)를 Apple Silicon Mac에서 mlx-lm으로 로컬 실행하며, 대회 기간에 학습시킨 LoRA 어댑터를 사용합니다. 인터넷 없이 작동합니다.

근거 자료: NASA의 Human Research Program 등 공개 출처를 요약한 지식 문단

협업: 자동 리뷰를 적용한 GitHub 풀 리퀘스트

창의적인 점

아이디어는 “지구가 멀어질수록 우주선이 더 깨어난다”입니다. 같은 앱이 연결 상태에 따라 역할을 바꿉니다. 제안하고, 그다음에는 스스로 조정하고, 그다음에는 2인 동의를 요구합니다. 판정은 규칙이, 결정은 사람이 하며, AI는 설명만 합니다.

팀이 고려한 점

AI는 틀릴 수 있으므로 긴급 결정에서는 배제하며, 검증에 실패한 설명은 보류합니다.

한 사람의 동의는 절대 두 번 계산될 수 없고, 도착하지 못한 패킷은 다음 교신 시간대에 다시 전송합니다.

화면에는 데이터가 합성 데이터이고, 환경 제어는 시뮬레이션이며, 의료 문단은 아직 전문가 검토를 받지 않았다는 점을 명시합니다.
