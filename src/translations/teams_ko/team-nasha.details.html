Mars BEACON: 화성의 모든 걸음에는 돌아올 길이 필요합니다

Mars BEACON은 Team NASHA가 NASA Space Apps Challenge 2026을 위해 개발한 브라우저 기반의 인터랙티브 화성 탐사 계획·임무 예행연습 플랫폼입니다. 유인 화성 탐사의 핵심 과제를 다룹니다. 우주비행사는 안전하게 돌아올 충분한 자원을 확보하면서 어떻게 과학적으로 가치 있는 지형을 탐사할 수 있을까요?

주로 지형을 시각화하는 기존 행성 지도와 달리, Mars BEACON은 실제 NASA와 USGS의 지리공간 데이터, AI 기반 지형 분석, 환경 관측, 자원을 고려한 경로 계획을 하나의 통합 임무 지원 인터페이스에 결합합니다.

작동 방식

주 연구 지역은 게일 크레이터 내 샤프산의 박스워크(boxwork) 지형 중 3 × 3 km 구역입니다. Mars Reconnaissance Orbiter의 HiRISE 고도 모델과 영상을 이용해 인터랙티브 3D 화성 환경을 구축합니다. Curiosity, NASA Mars Trek, REMS, RAD, DONKI의 추가 데이터셋은 지질, 환경, 우주기상 맥락을 제공합니다.

저희의 핵심 혁신은 Return Envelope(귀환 가능 영역)입니다. 지형을 고려하는 계획 시스템으로, 거주 모듈이나 지정된 지원 탐사차 대피 지점까지 실행 가능한 귀환 경로를 유지하면서 도달할 수 있는 위치를 계산합니다.

단순한 거리 반경에 의존하지 않고, 지형 난이도, 우주비행사의 이동 속도, 산소 소비량, 냉각수와 배터리 예산, 임무 시간, 설정 가능한 안전 여유분을 고려합니다. 두 우주비행사가 경로를 함께 이동하는 상황을 모델링하며, 이동은 더 느린 대원에게 맞추고 자원은 우주복별로 따로 평가합니다.

우주비행사와 임무 기획자는 다음을 할 수 있습니다.

  • 인터랙티브 3D 지도로 실제 화성 지형 탐색
  • 과학 중심, 균형, 안전 여유 중심 경로 비교
  • 지형 경사, 거칠기, 잠재적 장애물, 지질 특징 시각화
  • 우주비행사의 장비 하중, 이동 속도, 임무 시간, 자원 예산 조정
  • 임무 조건 변화에 따른 Return Envelope의 변화 관찰
  • 서로 연결된 Habitat(거주 모듈), Mission Control(관제), Tablet(태블릿), EVA(선외 활동), Visor(바이저), Rover(탐사차), Linked(연동) 인터페이스로 임무 예행연습
  • 탐사차 영상, 지형 분류 결과, 실험적 공간 재구성 확인
  • 추가 분석을 위한 경로와 임무 정보 내보내기

과학 데이터와 AI 통합

Mars BEACON은 NASA/USGS의 HiRISE 고도·영상 산출물, Curiosity 탐사차 관측, AI4Mars 지형 분류 데이터, REMS 대기 측정값, RAD 과거 방사선 관측, DONKI의 우주기상 정보를 통합합니다.

머신러닝 파이프라인은 탐사차 영상의 지형 분할과 파생 지형 분석을 지원합니다. 실험적 3D 재구성은 탐사차의 국지 관측이 궤도 관점을 어떻게 보완할 수 있는지 탐구합니다. 별도의 제제로(Jezero) 크레이터 데모는 부지 처리 파이프라인을 재사용하는 방법을 보여 줍니다.

기술 스택

애플리케이션은 React, TypeScript, Three.js, React Three Fiber, Zustand, Vite, 브라우저 Web Workers로 개발했습니다. 백엔드는 Python, FastAPI, SQLite/PostgreSQL을 사용합니다. 오프라인 과학 데이터 처리와 머신러닝 작업에는 Python 기반 지리공간·AI 도구를 사용합니다.

핵심 경로 계획 엔진은 4 m 계획 격자에서 작동하는 지형 인식 그래프 탐색 방식을 사용합니다. 브라우저에서 처리하므로 백엔드에 계속 연결하지 않아도 경로를 대화형으로 평가할 수 있습니다.

창의성과 혁신

Mars BEACON의 차별점은 행성 지도 제작과 사람 중심의 임무 의사결정을 통합한 데 있습니다.

과학 데이터셋을 따로따로 보여 주는 대신, 지형, 환경 맥락, 대원 자원, 과학 탐구 기회, 귀환 경로의 실행 가능성을 하나의 인터랙티브 시스템에서 연결합니다. 여러 임무 화면이 일관된 상태를 공유하므로, 사용자는 같은 탐사 시나리오를 서로 다른 운용 관점에서 살펴볼 수 있습니다.

설계는 과학적 추적 가능성, 대화형 탐색, 불확실성의 명확한 전달을 강조합니다. 관측 데이터, 파생 정보, 시나리오 가정, 실험적 산출물을 똑같이 확실한 것처럼 보여 주지 않고 구분합니다.

기대 효과

Mars BEACON은 실제 행성 데이터셋이 미래의 유인 탐사를 위한 더 이해하기 쉽고 자원을 고려한 계획 수립을 어떻게 지원할 수 있는지 보여 줍니다. 또한 우주비행사의 이동성, 행성 지질학, 로봇공학, 자율 임무 운용의 과제를 탐구하는 교육 플랫폼도 제공합니다.

현재 구현은 연구용이자 해커톤 프로토타입이며, 인증받은 우주비행사 안전 시스템이 아닙니다. Return Envelope는 문서화한 가정 아래에서의 실행 가능성을 나타낼 뿐, 임무 안전을 보장하지 않습니다. 향후 과제로는 모델 검증 강화, 장애물 탐지 개선, 불확실성 추정, 탐사차와 궤도 데이터를 잇는 더 정밀한 재구성이 있습니다.
