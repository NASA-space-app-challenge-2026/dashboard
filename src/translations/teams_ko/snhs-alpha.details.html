기능

Planet X · SPHEREx Observation Lab(https://nasaspaceappschallenge.marulee.dev/)은 서로 연결된 세 개의 작업 공간으로 구성됩니다.

1. 탐색. 태양에서 1,000 AU까지의 3D 태양계로, NASA/JPL 데이터를 갖춘 태양계 천체 476개(행성, 왜행성, 자연위성)와 JPL Small-Body Database의 해왕성 바깥 천체(TNO) 8,341개를 GPU 점 구름으로 그립니다. 사용자는 천체를 검색하거나 클릭해 궤도, 측정 또는 추정 질량, IAU의 행성 기준 세 가지를 충족하는지 확인합니다. 시간 조절 기능으로 기원전 3000년부터 서기 3000년까지의 위치를 재생합니다.

2. 실제 관측. 대상 10개의 실제 SPHEREx Level-2 분광 영상(QR2, QR3, DR1)을 제공합니다. 대상은 챌린지 공식 테스트 대상 5개(Barnard's Star, Epsilon Indi B, WISE 0855, RW Aurigae, R Draconis)와 명왕성, 목성, 토성, 천왕성, 해왕성입니다. 영상 산출물 40개는 서로 다른 시각에 같은 검출기로 촬영한 37쌍을 이루며, 시간 간격은 최대 17개월입니다. 사용자는 한 쌍을 나란히 또는 점멸 애니메이션으로 보고, 대비를 조절하고, 마우스를 올려 원본 픽셀값(MJy/sr)을 읽으며, 판단하기 전에 임무 자체의 FLAGS, VARIANCE, ZODI 레이어로 만든 품질 패널을 확인합니다.

3. 아홉 번째 행성 가설. 공개된 기준 모집단인 합성 아홉 번째 행성 궤도 100,000개(Brown & Batygin 2021)를 불러옵니다. ZTF, DES, Pan-STARRS1 탐사에서 이미 검출되었을 궤도를 제외하면 1,000 AU 이내에 20,406개가 남습니다. 도구는 HEALPix 하늘 칸을 그 안에 들어오는 궤도 수에 따라 순위를 매기고, 사용자가 궤도 하나를 가설로 고르게 한 뒤, 광행시간 보정을 적용해 하늘 경로를 계산하고, 실제 TNO 궤도와 비교하며, NASA/IPAC IRSA의 Moving Object Search Tool(MOST)에 조회해 예측 위치를 관측 범위에 포함한 SPHEREx 노출 목록을 보여 줍니다.

증거. 관측 작업 공간과 가설 작업 공간 모두에서 사용자는 판단을 작성하고 저장하고 JSON이나 CSV로 내보낸 뒤 나중에 복원할 수 있습니다. 기록에는 관측 ID, 시각, 원본 URL, SHA-256 해시가 보존됩니다.

챌린지에 대한 해법

챌린지는 SPHEREx 영상을 표시하고 시간에 따른 변화를 쉽게 볼 수 있게 하는 일반 공개용 웹 도구를 요구하며, 지정된 대상 5개로 테스트합니다. 5개 모두 실제 SPHEREx 다중 시점 데이터와 점멸 애니메이션으로 포함했습니다. 선택 고려 사항 중에서는 다음을 구현했습니다. 오염 플래그를 포함한 메타데이터 표시, 여러 검출기 배열(D1, D3, D6)의 데이터와 각 노출의 파장, 인터페이스를 바꾸지 않고 새 SPHEREx 공개 자료를 추가할 수 있는 매니페스트 기반 관측 목록(DR1 영상은 공개 후 며칠 안에 추가), 모든 FITS 처리에 Astropy 사용.

왜 중요한가

해왕성은 누군가 눈으로 보기 전인 1846년에 계산으로 예측되었습니다. 아홉 번째 행성은 오늘날의 비슷한 예측입니다. 지구 질량의 5~10배인 행성이 있다면 행성 이동 이론을 검증하고, 먼 카이퍼대 천체들의 몰려 있는 궤도를 설명하며, 다른 별 주위에는 흔하지만 우리 태양계에는 없는 유형의 행성을 가까이에서 보여 주는 사례가 될 것입니다. 앞선 탐사들은 예측 위치의 약 78%를 이미 배제했습니다(Brown, Holman & Batygin 2024). 저희 도구는 남은 탐색 영역이 어디인지, 실제 전천 적외선 탐사가 그곳에서 무엇을 촬영했는지, 그런 데이터를 어떻게 비판적으로 판단해야 하는지를 대중에게 보여 줍니다.

작동 원리

- 빌드 파이프라인(Python 3.12, Astropy, NumPy): IRSA에서 SPHEREx 원본 FITS 파일(각 약 66 MB)을 내려받고, SHA-256 해시를 확인하고, 예측된 대상 위치 주변을 원본 픽셀 그대로 잘라내며, FLAGS, VARIANCE, ZODI 평면과 분광 WCS를 읽어 검증된 캐시를 작성합니다. 대상 위치는 SPHEREx 우주선 기준의 JPL Horizons 관측자 천체력(태양계 천체)과 SIMBAD 고유운동(Epsilon Indi B)에서 가져옵니다.

- 서버(Node.js 22, 내장 HTTP와 워커 스레드, 외부 런타임 패키지 없음): API(OpenAPI 계약)를 제공하고, 원본 해시를 검증하고, 궤도 예측과 실시간 MOST 조회를 실행하며, 증거 파일을 저장합니다.

- 프런트엔드(TypeScript, React, Vite, Three.js/WebGL, i18next): 3D 장면, 비교 뷰어, 증거 패널을 영어, 한국어, 일본어, 중국어 번체, 프랑스어로 제공합니다.

- 호스팅: AWS EC2(m7i.xlarge, Ubuntu 24.04), nginx, HTTPS.

- 테스트: Node와 Python 단위 테스트, Vitest, TypeScript strict 모드, Ruff, Chrome 브라우저 점검. 보간한 행성 위치를 별도의 JPL Horizons 조회 27건과 비교한 결과, 가장 큰 차이는 약 19 km였습니다.

테스트 방법

모든 요청, 버그, 과학 관련 질문은 팀원 누구나 작성할 수 있는 하나의 공유 트래커에 모았습니다. 여기에는 번호가 붙은 항목 41개(R001~R041)가 있으며, 각 항목에 작성자, 유형, 위치, 상태(완료, 보류, 반려)를 기록했습니다.

- 명세 및 과학 검토(12개 항목, 11월 13일 기획 단계): 과학 검토 담당자가 기획 수치를 손으로 다시 계산했습니다. 예를 들어 9월 29일부터 10월 2일까지 명왕성의 예측 이동량(72.3 arcsec, 픽셀당 6.15 arcsec 기준 SPHEREx 픽셀 약 11.8개), 511.6일 동안 Epsilon Indi B의 고유운동(6.56 arcsec, 약 1.07픽셀), 환산식 1 MJy/sr = 픽셀당 0.889 mJy 등입니다.

- 버그와 사용성(29개 항목, 행사 기간): 테스터들은 선택 후 깨지는 행성 텍스처, 일관되지 않은 확대 거리, 연결된 노출이 없는 대상의 빈 비교 패널, 다시 열 수 없는 측면 패널, 복원되지 않는 증거 JSON, 휴대전화에서 깨지는 레이아웃을 보고했습니다. 대부분은 행사 기간에 수정했으며, 휴대전화에서는 이제 깨진 화면 대신 명확한 안내가 표시됩니다.

- 범위: 둘째 날의 트래커 항목 하나를 계기로 은하 지도, 우주 역사, 혜성, 물리 실험실 기능을 제거하고 아홉 번째 행성에 다시 집중했습니다. 기능 요청 2건(생명체 거주 가능 영역, 퀘이사)은 주제에서 벗어나 반려했습니다.

창의적인 점

- 가설을 예측으로, 예측을 실제 망원경의 관측 범위로, 결과를 저장된 증거 기록으로 하나의 흐름 안에서 연결합니다.

- 과학적 정직성을 설계 요소로 다룹니다. 모든 화면은 값이 관측값인지, 계산값인지, 가설값인지 밝히고, 어떤 결론보다 먼저 품질 플래그를 보여 줍니다.

- 실제 TNO 궤도 8,341개를 선택한 아홉 번째 행성 궤도와 긴반지름, 이심률, 궤도 경사각으로 비교할 수 있습니다.

고려한 요소

- 볼거리보다 정확성: 3D 장면의 크기와 거리는 압축한 것임을 표시하고, 알 수 없는 질량은 알 수 없는 상태로 둡니다. SPHEREx는 노출마다 다른 파장을 관측하므로, 밝기 변화만으로는 변광으로 간주하지 않습니다.

- 데이터 권리: 모든 출처의 저작권 표기와 이용 조건을 유지하고, NASA 로고를 사용하지 않으며, AI 생성 이미지가 관측 자료를 대신하지 않습니다.

- 성능: 무거운 FITS 처리는 미리 수행해 사이트의 반응 속도를 유지합니다.

- 개인정보 보호: 사이트는 승인된 닉네임만 표시하며 개인정보를 저장하지 않습니다.

- 범위: 해커톤 기간에 은하, 외계행성, 우주론 기능을 제거해 1,000 AU 이내의 태양계와 챌린지 자체에 집중했습니다.

한계와 다음 단계

- 영상은 각 예측 위치를 중심으로 원본 픽셀 그대로 잘라낸 것이며 아직 서로 정합되지 않았으므로, 도구는 움직임이나 밝기를 측정하지 않습니다. 산출물 40개 중 23개는 분광 보정이 검증되지 않았으며, 인터페이스에 이를 표시합니다.

- MOST의 관측 범위 일치는 노출 영상에 예측 위치가 포함된다는 뜻입니다. 검출이 아닙니다.

- 다음 단계: 임의의 하늘 위치에 대해 RA/Dec 및 URL 검색과 요청 시 잘라내기, 영상 정합과 차이 영상, Gaia DR3와 WISE 겹쳐 보기, CSA NEOSSat 데이터, 인공 천체 주입을 이용한 감도 시험, 모바일 지원.
