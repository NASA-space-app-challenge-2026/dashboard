FireGap: 미세중력 화재 연구를 위한 증거 기반 인텔리전스

문제

불은 미세중력에서 다르게 거동하며, 그 차이를 이해하는 것은 미래의 우주선과 달·화성 거주지에 필수적입니다. NASA는 Saffire, BASS-II, SoFIE-GEL 등 중요한 연소 연구를 수행했지만, 관련 결과는 기술 보고서, 실험 기록, 연구 저장소에 분산되어 있습니다.

특정 재료나 환경 조건을 탐색하는 연구자는 여러 자료를 찾고, 측정값을 비교할 수 있는지 판단하며, 어떤 실험 조건이 빠져 있는지 파악해야 할 수 있습니다.

FireGap은 이 과정을 더 접근하기 쉽고 투명하며 재현 가능하게 만들기 위해 만들었습니다.

해결책

FireGap은 검증된 NASA 연소 증거를 환경 조건, 정량 비교, 연구 공백과 연결하는 인터랙티브 연구 대시보드입니다.

사용자는 다음을 할 수 있습니다.

  • NASA 기술 자료 6건에서 도출한 검증된 증거 기록 25건을 살펴봅니다.
  • 개별 시험 23건과 실험 종합 판정 2건을 구분합니다.
  • 측정 단위와 실험 맥락을 유지한 채 선택한 기록을 최대 3건까지 비교합니다.
  • 재료, 중력, 산소 농도, 공기 유속, 압력 조건을 입력해 관련 증거를 검색합니다.
  • 결정론적 증거 요약, 관련도 순위, 보유 데이터셋의 공백을 검토합니다.
  • 검색 가능한 별도 카탈로그에서 NASA Physical Sciences Informatics(PSI) 연구 과제 24건을 열람합니다.
  • NASA 1차 자료 링크를 따라가 근거가 되는 증거를 확인합니다.

작동 방식

FireGap은 실험 측정값에 참고 출처와 문서 내 위치를 연결해 선별한 과학 데이터셋을 사용합니다.

증거 엔진은 사용자가 선택한 조건을 문서화된 실험 조건과 비교합니다. 결과는 추적 조건과 직접 일치, 관련 있음, 현재 데이터셋에서는 확인되지 않음으로 분류됩니다.

문서화되지 않은 측정값은 0이나 추정값으로 처리하지 않고 알 수 없음으로 남겨 둡니다. 또한 비교 시스템은 물리적으로 다른 관측량을 구분하며, 호환되지 않는 측정값을 합쳐 오해를 부르는 차트를 만들지 않습니다.

BASS-II 데이터 연계 시범 작업은 기존의 검증된 기록 7건을 NASA 원본 시험 매트릭스의 항목과 연결해, 발표된 측정값을 그 바탕이 되는 실험 기록까지 추적할 수 있음을 보여 줍니다. 이 연계가 추가로 검증된 실험을 의미하지는 않습니다.

유료 AI에 의존하지 않는 과학적 인사이트

FireGap의 핵심 기능인 Scientific Insights(과학적 인사이트)는 결정론적 데이터 처리로 작동합니다. 외부의 유료 언어 모델 API 없이 요약, 증거 순위, 조건 충족 범위, 연구 공백 설명을 생성합니다.

시스템은 각 결과의 근거를 이해하고 추적할 수 있도록 설계했습니다. 증거의 관련도는 화재 확률, 위험 예측, 우주선 안전 인증으로 제시하지 않습니다.

기술

FireGap은 Next.js, React, TypeScript, Tailwind CSS, Recharts, 서버 측 API 라우트로 만들었습니다. 요청 검증에는 Zod를, 자동화 테스트에는 Vitest를, 웹 배포에는 Vercel을 사용합니다.

ChatGPT와 Claude Code를 포함한 AI 지원 개발 도구가 기획, 프로그래밍, 테스트, 문서화를 도왔습니다. 과학 측정값과 참고 출처는 AI가 생성한 것이 아니라 NASA 자료에서 가져왔습니다.

창의성과 영향

FireGap은 초점을 화재 시나리오 예측에서 현재 실험 지식의 한계를 이해하는 것으로 옮깁니다.

근거 없는 위험 점수를 제시하는 대신, 연구자가 세 가지 실질적인 질문에 답하도록 돕습니다.

  1. NASA가 실제로 측정한 것은 무엇인가?
  2. 어떤 결과를 의미 있게 비교할 수 있는가?
  3. 어떤 조건이나 측정값이 아직 충분히 문서화되지 않았는가?

이 접근 방식은 문헌 검토, 실험 계획, 그리고 미세중력 연소 연구에 대한 더 근거 있는 해석을 뒷받침할 수 있습니다.

한계와 향후 과제

현재의 검증된 증거 모음은 기록 25건으로, NASA의 모든 연소 연구를 완전히 대표하지 않습니다. 시료 형상, 점화 방식 같은 요인도 중요하므로, 추적하는 환경 조건이 일치해도 완전한 물리적 동등성이 보장되지는 않습니다.

PSI 연구 과제 카탈로그는 연구 메타데이터를 제공하는 것이며, 검증된 실험 측정값 24건이 추가되는 것은 아닙니다.

향후에는 검증된 정량 데이터셋을 확대하고, 명시적 계산과 NASA 출처 인용으로 뒷받침되는 연구 질문 중심의 결정론적 분석을 도입할 수 있습니다.

FireGap은 연구 증거 탐색 도구이며, 검증된 화재 위험 예측 시스템이나 우주선 안전 인증 시스템이 아닙니다.
