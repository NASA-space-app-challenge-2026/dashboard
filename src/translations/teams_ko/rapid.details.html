기능과 작동 방식

Fire Evidence Explorer는 NASA의 Physical Sciences Informatics(PSI) 아카이브에 있는 24개 연소 연구를 다루는 공개 웹 페이지입니다. 무엇을 어디에 만드는지 입력하면 세 단계로 답합니다.

찾기: 코드가 질의를 조건(산소, 압력, 유동, 연료, 시료 형상, 목적)으로 해석하고 41개 시험 구성과 비교합니다. 가중 유사도로 0에서 100까지의 일치 점수를 냅니다. 어떤 언어 모델도 점수를 만들거나 바꾸지 않습니다.

비교: 파이프라인이 14개 NASA 표를 읽어 시험 1,824건의 표 하나로 만들며, 각 값은 해당 NASA 파일과 행에 연결됩니다. 시험은 해당 연구가 여섯 가지 화재 안전 질문 중 하나를 목적으로 명시한 경우에만 그 질문에 집계됩니다.

해석: 페이지는 질문별로 NASA 문서가 보고한 내용을 인용한 뒤, 필요한 값이 NASA의 표에 있는지, 원시 아카이브(목록상 파일 60,866개, 13.47 TB)에만 있는지, PSI에 기록이 없는지를 알려 줍니다.

예시: "lunar habitat cotton fabric"(달 거주지 면직물)을 입력합니다. 그러면 면직물, 그리고 챌린지의 달 프리셋에서 가져온 산소 30%, 70.3 kPa로 해석합니다. 가장 가까운 것은 SAFFIRE-II(일치 점수 75.0)와 SAFFIRE-I(74.5)입니다. Saffire는 산소 약 22%에서 면-유리섬유 직물을 연소시켰습니다(연료 유사도 1.00, 산소 유사도 0.24와 0.22). 3위는 시험한 산소 범위에 30%가 포함되는 결과 중 가장 좋은 ACME-BRE(62.6, 연소하는 고체를 모사하는 기체 버너, 21~40%)가 차지합니다. 이어서, 산소 30% 이상이면서 70.3 kPa 이하인 조건에서는 집계된 시험이 없습니다. 산소를 기록한 고체 연료 시험 139건 중 22.2%를 넘는 것은 없고, 압력을 기록한 것도 없습니다. 챌린지 설명은 미세중력과 정상 중력의 결과가 중간 중력의 범위를 한정할 수 있다고 제안하지만, 페이지는 세 가지 재료에 대한 NASA 낙하탑 시험(Olson and Ferkul, AIAA 2012-3492, NTRS 20130010991, Table I)을 보여 주며, 여기서 달 중력에서의 산소 한계는 0 g와 1 g 모두에서보다 낮았습니다.

이점

설명 하나로 다음을 얻습니다. DOI가 있는 가장 가까운 NASA 실험, 원본 행이 포함된 CSV 형식의 일치 시험, 가장 먼저 열어 볼 원시 파일, 집계된 시험이 없는 조건. 관측값, 인용한 NASA 기준, 공백은 서로 분리해 보여 줍니다.

기대 효과

학생, 연구자, 엔지니어는 유인 환경에 대해 NASA의 시험이 무엇을 다루고 무엇을 남겨 두었는지 확인할 수 있어, 새로운 실험과 데이터 요청이 공백을 겨냥할 수 있습니다. 환경은 시험 건수로 비교합니다. ISS 선실에서는 6개 질문 중 4개에 집계된 시험이 있고, 달 거주지에서는 6개 중 1개입니다(71.2~72.4 kPa에서의 FLEX 액적 시험 17건으로, 70.3 kPa보다 약 1~2 kPa 높음).

도구, 프로그래밍 언어, 하드웨어와 소프트웨어

Python 3.13(파이프라인, 순위, 검사); JavaScript, HTML, CSS(정적 페이지; Node.js가 순위 이식본을 Python과 대조 검사); shell. 호스팅: GitHub Pages와 Actions. 라이브러리: pandas, NumPy, scikit-learn, Pillow, Chromium을 사용하는 Playwright, FFmpeg. 언어 모델: Ollama 0.40.16을 통해 로컬에서 실행하는 OpenAI gpt-oss:20b(오픈 웨이트, Apache-2.0). Claude Code(Anthropic)가 팀의 지휘 아래 코드를 작성했습니다. 하드웨어: Apple M4 Pro 칩과 48 GB 메모리를 갖춘 MacBook Pro. 순위에 대한 단위 테스트 83개가 통과합니다.

창의성

근거가 담고 있는 것만큼이나 근거가 끊기는 지점을 분명하게 보여 주며, 아카이브가 아니라 질문에서 출발합니다. 코드가 NASA의 시험 식별자를 따라 표와 원시 파일을 찾아갑니다. 언어 모델은 코드의 통제 안에서 작동합니다. 코드가 조회한 번호 붙은 사실을 인용하는 문장만 작성할 수 있고, 모든 숫자는 그 사실들에 있어야 하며, 검사를 통과하지 못한 문장은 제거됩니다.

팀이 고려한 점

이 도구는 연구 탐색 도구입니다. 안전 판정을 내리지 않으며, 시험하지 않은 조건에 대한 예측도 하지 않습니다. 일치 점수와 순서는 NASA PSI 데이터를 바탕으로 Team RAPID가 계산한 것입니다. 모델이 작성한 카드 문장 70개 중 33개가 코드 검사와 두 번째 AI 세션의 검토를 거쳐 표시됩니다. 도우미는 로컬 설치판(./install.sh, ./run.sh)에서 실행되며, 공개 페이지는 녹화된 답변을 재생합니다. 74개 평가 질문에서 전체 파이프라인은 채점 항목의 94%를 올바르게 읽었고(모델 단일 호출: 84%), 인용한 사실에 없는 숫자는 하나도 표시하지 않았습니다(단일 호출: 36). 범위와 가중치는 팀이 선택한 것입니다. 다음 과제: 연소 연구자에게 규칙 검토 요청, 더 많은 환경 추가, PSI에 부분 중력 데이터가 추가되면 파이프라인 재실행.
